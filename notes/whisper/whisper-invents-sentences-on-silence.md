# Whisper 는 무음에서 "없음"을 출력하지 않는다 — 학습 잔재 문장을 지어낸다

> 발화가 거의 없는 저볼륨 녹음을 전사하면 Whisper 는 빈 결과 대신 그럴듯한 완성 문장을 만들어낸다.
> 유튜브 아웃트로체("다음 영상에서 만나요") 같은 학습 데이터 잔재가 전형이다.
> 반복 횟수 검사만으로는 못 잡는다 — **반복이 적어도 전사 전체가 환각일 수 있어**, 판정에는 볼륨 측정을 병행해야 한다.

**상태**: 활성
**마지막 검증**: 2026-08-14

## 왜 그렇게 동작하나

- `[실측]` 약 3분짜리 발화 없는 테스트 녹음(mean_volume -46.5 dB)을 mlx-whisper large-v3 로 전사하자, 결과 8줄 전부가 실제로 말한 적 없는 완성 문장이었다(아래 출력). 같은 줄 최다 반복이 5회에 그쳐 반복 기반 환각 검사는 통과했다.
- `[추정]` Whisper 는 디코더가 언어모델이라 무음 구간에서도 "가장 그럴듯한 다음 토큰"을 뽑는데, 학습 데이터(자막 딸린 영상)에 흔한 인트로/아웃트로 문구가 무음·배경음의 최빈 대응이라 그쪽으로 수렴하는 것으로 보인다. 학습 코퍼스 구성은 직접 확인하지 않았다.
- `[실측]` ffmpeg `volumedetect` 의 mean/max 조합으로 원인을 가른다: 이번 케이스는 mean -46.5 dB / max -2.8 dB — 평균은 무음인데 피크는 잡혔으므로 **입력 장치는 정상이고 발화가 없었던 것**이다.
- `[추정]` OS 가 마이크 권한을 차단하면 장치가 제로 샘플만 내놓아 mean/max 모두 -90 dB 안팎의 완전한 디지털 무음이 된다 — 권한 차단 상태를 직접 녹음해 실측하지는 않았다.

## 확인하는 방법

```
$ ffmpeg -hide_banner -i recording.wav -af volumedetect -f null - 2>&1 | grep volume
mean_volume: -46.5 dB
max_volume: -2.8 dB

$ cat transcript.txt        # 3분 무발화 녹음의 전사 결과 (8줄 전부 환각)
이곳은 대구의 한 대중교통기관입니다.
대구의 한 대중교통기관은
대구의 한 대중교통기관을 포함한
... (같은 줄 5회 반복)
다음 영상에서 만나요.
```

## 이 노트가 틀렸다면

- 비슷한 저볼륨(mean -40 dB 이하) 무발화 녹음을 전사했는데 빈 결과나 무음 표기가 나온다 → 모델·옵션 개선으로 핵심 주장이 좁아졌거나 틀렸다.
- 마이크 권한을 차단하고 녹음했더니 max_volume 이 0 dB 근처로 나온다 → 권한 차단 = 완전 무음 `[추정]` 폐기.
- 발화가 충분한 정상 녹음(mean -20 dB 대)에서도 같은 잔재 문구가 대량 출현한다 → "무음이 원인"이라는 범위 설정이 틀렸다.

## 적용 범위

- mlx-whisper + `mlx-community/whisper-large-v3-mlx`, `--language ko --condition-on-previous-text False --hallucination-silence-threshold 2` 상태에서 실측 — **반복 억제 옵션을 켠 상태에서도** 발생했다.
- 한국어 전사 기준. 다른 언어는 잔재 문구만 다를 뿐 같은 현상이 보고되어 있다 `[추정]` (직접 확인 안 함).

## 함정

- ⚠️ 환각 검증을 반복 횟수(`sort | uniq -c`)로만 하면 이런 케이스를 "정상"으로 판정한다. 짧은 녹음일수록 반복이 임계치에 못 미친다. **회의 길이 대비 전사가 비정상적으로 짧으면 volumedetect 부터** 볼 것.
- 💡 max 는 정상인데 mean 이 극단적으로 낮으면 장비 탓이 아니라 "마이크에서 멀었거나 말이 없었던" 쪽이다 — 재녹음 안내 시 원인 지목을 다르게 해야 한다.
